# Studens-rate-TOP-IT
# 🏆 Svelte 5 Interactive Leaderboard

Интерактивная таблица участников с автоматической сортировкой рейтинга в реальном времени. Проект демонстрирует возможности новой системы реактивности (**Runes**) в **Svelte 5**.

## ✨ Особенности (Features)
* ⚡ **Реактивность на Svelte 5:** Использование `$state` и `$derived.by` для мгновенного обновления интерфейса.
* 📊 **Умная сортировка:** Участники автоматически ранжируются по общему количеству очков (`points`).
* 👥 **Групповой рейтинг:** Расчет позиции участника как в общем зачете, так и внутри его группы (класса).
* ⚙️ **Динамическое управление:** Возможность добавлять новых участников с уникальными `id`, удалять их и изменять рейтинг (`+50` / `-50` очков) в один клик.

## 🚀 Технологический стек
* Svelte 5 (Runes)
* TypeScript
* HTML5 / CSS3

## 🛠 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите сервер для разработки:
   ```bash
   npm run dev
   ```
